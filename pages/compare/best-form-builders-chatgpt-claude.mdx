## What MCP means here

MCP (Model Context Protocol) is an open standard that lets an AI assistant such as ChatGPT or Claude call tools in another product. A form builder with an MCP server lets you create a form, change it, publish it or read its responses by asking the assistant, instead of opening the form builder yourself. What you can do depends on which tools the server exposes and on your plan in the form builder.

### 1. Makeform: best for depth of form operations

Makeform's hosted MCP server exposes 33 tools as of November 2026, covering prompt-based creation, proposed and applied AI edits, publishing, response work and analytics. We rank it first for that breadth, unlimited free form submissions and explicit two-step publish confirmation, while Tally and Typeform are also listed in Claude's connector directory.

**Free plan:** Unlimited forms and submissions within fair-use guidelines; the AI builder generates up to 50 questions in one go on Free.

**Paid from:** Pro is $29/month monthly or $19/month billed yearly ($228/year).

**Good:**

- Tools for duplicating forms, listing, exporting and summarizing submissions, analytics, webhooks and embed code.
- OAuth account linking for Claude and ChatGPT, with interactive Makeform cards in ChatGPT; API keys as Bearer tokens for clients such as Codex CLI.
- Publishing requires explicit confirmation instead of a single unchecked action.

**Watch out:**

- Makeform is not yet in Claude's connector directory; in Claude you add it as a custom connector (mcp.makeform.ai).
- Form deletion is dashboard-only, and translation through MCP requires Pro.
- Branding removal, custom domains and collaboration require Pro.

The server uses Streamable HTTP. See [Makeform plans and pricing](/plans-and-pricing), or [Create a form with AI](https://www.makeform.ai/create) in the web builder.

### 2. Tally: best for directory setup with unlimited submissions

As of November 2026, Tally is listed in ChatGPT's directory and Claude's connector directory, with free access for all Tally users. Its beta MCP supports creating, editing and listing forms and reading submissions, making it a close alternative when these core operations cover your work.

**Free plan:** Unlimited forms and submissions within fair-use guidelines; free AI creation and editing.

**Paid from:** Pro is $29/month monthly or $24/month billed yearly.

**Good:**

- Directory listings in ChatGPT and Claude.
- MCP authentication through OAuth or an API key at https://api.tally.so/mcp.
- Tally's own AI builder also accepts screenshots and PDFs on Free.

**Watch out:**

- The MCP server is labeled beta.
- Free uploads are limited to 10 MB per file; branding removal requires Pro.

### 3. Typeform: best for building and analyzing small-volume forms

As of November 2026, Typeform's MCP server works with ChatGPT and Claude and is listed in both directories. It supports building and editing forms and analyzing responses on every Typeform plan, but the free response allowance is small.

**Free plan:** Unlimited typeforms with 10 responses/month across all forms; AI chatbot form building and logic are included.

**Paid from:** Basic is $28/month billed yearly or $39/month monthly.

**Good:**

- Directory listings in both assistants.
- MCP access on every plan, with form editing and response analysis.

**Watch out:**

- MCP access does not increase the 10-response monthly free allowance.
- File uploads, payments and knowledge quiz mode are paid-only; branding removal starts with Plus at $56/month billed yearly.

### 4. Jotform: best for using Jotform workflows from an assistant

As of November 2026, Jotform MCP works with ChatGPT, Claude, Manus and Cursor. Its five tools cover listing, creating and editing forms, creating submissions and getting submissions; Jotform's broader native integration selection is a reason to choose it over Makeform.

**Free plan:** Starter includes 5 active forms, 100 submissions/month, 10,000 form views/month, 100 fields per form and 100 MB upload space; MCP has no extra charge beyond your plan.

**Paid from:** Bronze is $39/month monthly or $34/month billed annually.

**Good:**

- Support for multiple assistant clients.
- A create-submission tool as well as form editing and submission retrieval.
- Jotform advertises 150+ native integrations.

**Watch out:**

- MCP authentication is OAuth only.
- Its five exposed tools cover a narrower set of operations than Makeform's 33.
- Starter retains Jotform branding and has active-form and monthly submission caps.

## FAQ

### How do I connect Makeform to ChatGPT or Claude?

Makeform is in [ChatGPT's app directory](https://chatgpt.com/plugins/plugin_asdk_app_69e57d90af9881919a0131fbe58221c7); in Claude you add it as a custom connector (mcp.makeform.ai). In ChatGPT, open the Makeform app from the directory and sign in; in Claude, add https://mcp.makeform.ai as a custom connector and sign in with your Makeform account. As of November 2026, Tally and Typeform can be added from both directories.

### Can I connect Makeform without an API key?

Yes. Claude and ChatGPT support OAuth account linking for Makeform, while other MCP clients can authenticate with an API key as a Bearer token.

### Can an assistant publish or delete a Makeform form?

Publishing through MCP requires a two-step process with explicit confirmation. Deleting forms is not exposed through MCP and must be done in the dashboard.

### Does free MCP access mean unlimited responses?

No; the underlying plan still applies. As of November 2026, Tally and Makeform offer unlimited form submissions within fair use, while Typeform Free allows 10 responses/month and Jotform Starter allows 100 submissions/month.

### Are Makeform's headless backend limits the same as its form limits?

No. Its headless backend is a bounded private preview, with 1 enabled endpoint and 50 headless submissions/month on Free; the unlimited free submission allowance described here is for forms.
