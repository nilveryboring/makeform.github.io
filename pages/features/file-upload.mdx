# File upload

File Upload lets respondents attach files with configurable file type and size restrictions and is available in the form builder. It is free on every plan, with up to 20 MB per file on Free and up to 1 GB per file on Pro and Business.

Makeform is a free AI form builder: describe what you want to collect and it builds the form for you, with unlimited forms and submissions on the free plan.

Free allows up to 20 MB total per submission, 3 file upload fields per form, and 10 files per field. Pro and Business allow up to 1 GB per file, 2 GB per submission, and 100 file upload fields per form.
