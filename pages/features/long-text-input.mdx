# Long text input

Long Text fields collect multi-line answers such as feedback, explanations, notes, or descriptions. They are free on every plan; select the field in the form builder to set its initial height.

Makeform is a free AI form builder: describe what you want to collect and it builds the form for you, with unlimited forms and submissions on the free plan.

### Set the initial height

You can choose how tall a Long Text field is before a respondent starts typing:

1. Select the Long Text field in the Builder.
2. Find <span className="text-cyan-500 font-semibold bg-cyan-100 px-2 py-1 rounded">Initial height</span> in the field settings.
3. Enter a value from **1 to 10 lines**.
4. Preview the form, then publish it when you are ready.

A one-line Long Text field starts as compact as a Short Text field while still allowing a multi-line answer. As the respondent types, the field automatically grows to fit longer content.

The setting changes only the field's starting height. It does not limit the answer length or change submitted data.

Existing Long Text fields without an Initial height value keep their previous default height. After changing this setting on a published form, **publish the form again** for the new height to appear on the public form and existing embeds.
