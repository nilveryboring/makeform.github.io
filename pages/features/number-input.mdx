# Number Input

Number input lets respondents enter numeric values with optional minimum, maximum, and step constraints. You can add it in the form builder for free on every plan.

Makeform is a free AI form builder: describe what you want to collect and it builds the form for you, with unlimited forms and submissions on the free plan.
